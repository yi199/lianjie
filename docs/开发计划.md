# 练界 · 开发计划 v1

> 模块拆分、阶段排期与验收标准。设计依据见 [`技术方案.md`](./技术方案.md)，接口细节见 [`后端接口契约.md`](./后端接口契约.md)。
> 估算口径：1 人全栈 + AI 辅助。估算用来定顺序和依赖，不用来承诺日期。

---

## 0. 起点

**已有**

- 客户端 8 个页面 + 数据层 `db.js`，自测 113 + 42 项全绿
- 105 个动作、6 套官方方案、自定义方案编辑器
- 纯本地存储，无账号、无网络依赖
- `server/` 下有一份 Go 后端骨架（按 v1 契约写的，需要按 v2 调整）

**缺口**

| 缺口 | 后果 |
|---|---|
| 没有账号与多设备 | 换手机、重装即丢全部记录 |
| 本地单 key 上限 1MB | 约 31 个月写满 |
| 取消勾选不落库（现存 bug） | 页面显示未勾选，统计仍然算它 |
| 没有身体指标 | 只能可视化训练量，不能可视化身体 |
| 无备案 / 域名 | 正式版上不了线 |

---

## 1. 目标

1. **记录不丢**：换设备能拉回来，断网也能记
2. **身体素质可视化**：在训练量之外，加上体重 / 体脂 / 围度 / 力量水平
3. **可上线**：备案、HTTPS、审核通过、有备份和监控

---

## 2. 已拍板的决策（2026-10-29）

| # | 决策 | 结论 |
|---|---|---|
| D1 | 后端 | 自建，**Go** + PostgreSQL |
| D2 | 取消勾选 | **墓碑**（`done=false`），同步关闭时直接删 |
| D3 | 本地存储 | **按月分 key，保留全量**，不做 90 天截断 |
| D4 | 训练日队列 | 客户端推导，服务端不存 |
| D5 | 设置 / 换动作 / 自定义方案 | 合并为一份配置文档，整份同步 |
| D6 | 增量游标 | 服务端版本号 `rev`，不用时间戳 |

详细理由见技术方案 §1 决策记录。

```
第 1 天 ├─ P0 提交备案 ─────────────────────────────── 等待 ──┤
        ├─ P1 后端（6.5 天）──────────┐
```

## 5. 验收标准

### P1 后端

集成测试（真 Postgres）全部通过，覆盖：

| 场景 | 期望 |
|---|---|
| 同一组重复上传 3 次 | 服务端只有 1 行 |
| 上传的行赢了 LWW | 响应里不回传这行（去回声） |
| 上传比服务端旧的行 | 不覆盖；响应里回传服务端赢家 |
| 时钟慢很多的设备写入 | 其他设备按游标一定拉得到（v1 协议会漏） |
| 取消勾选（墓碑） | 其他设备收到墓碑；统计不再计入 |
| 新设备拉取 1234 行 | 分页拉全，不多不少 |
| 一批里混有坏行 | 坏行进 `rejected`，好行照常写入 |
| 8 个写入者并发 + 1 个拉取者边拉边推进游标 | 拉取者最终看到全部 480 行，一行不漏 |
| 用户 B 拉取 | 看不到用户 A 的任何数据；无 token / 假 token → 401 |
| 生产模式用默认 JWT 密钥启动 | 拒绝启动 |

### P2 前端存储

- 现有 113 + 42 项自测全绿（页面没被破坏的硬证据）
- 老版本 `lj.sets` 自动迁移成分月格式，条数不变，示例数据被识别
- 取消勾选后：页面、战报、统计三处都不再算这一组

### P3 / M1 端到端

- `test-sync.js` 两台模拟设备：A 记录 → B 拉到；A 取消 → B 消失；A 改设置 → B 训练日队列一致
- 飞行模式完整练一次 → 恢复网络后 30 秒内自动上传完
- 上传途中继续改数据 → 新改动不丢
- 后端停掉 → 小程序照常记录、照常看统计，无报错弹窗

### P4 真机

- 两台真机交替记录一周的训练，数据完全一致
- 一台手机时钟手动调慢 1 天 → 另一台仍能看到它的记录
- 杀进程、切后台、弱网下同步不重不漏

## 7. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| **备案卡住** | 正式版上不了线 | 第一天提交；开发不受影响（§技术方案 2）；备选云托管免备案 |
| 同步漏数据 / 出重复 | 用户记录错乱，难查 | 自然主键 + rev 游标 + 并发集成测试（§5 P1）；P4 专门做改时钟测试 |
| 老用户首次全量上传量大 | 首次同步慢 | 分批 500 行；一年约 2400 行 = 5 批，几秒完成 |
| 用户在新设备上抢先走完引导 | 新配置覆盖旧设备的配置 | 欢迎页在同步完成前先尝试拉取；被覆盖的只是设置，训练记录不受影响 |
| 本地存储写满 10MB | 无法再记录 | 按月分 key 后约 20 年；届时再做本地归档 |
| 审核被拒 | 上线延期 | 隐私协议提前写；不采集与功能无关的信息 |
| 只有 1 人开发 | 进度不稳 | 每个阶段结束都是可停状态（§4） |
