## 4. 提审时怎么填（话术，可直接抄）

**功能描述（后台「功能页面」/审核备注）**

```
本小程序为个人开发的力量训练记录工具，无需登录、无支付、无广告、无社交。
功能：①按用户自选的水平/频率/场地生成训练计划；②记录每组的重量与次数；
③生成本地统计与训练可视化；④支持本地备份与恢复。
数据说明：所有数据仅保存在用户手机本机，当前版本未接入任何服务器，
不上传任何个人信息。已提供「删除我的全部数据」入口与隐私政策页。
```

**审核备注（如果被要求补充）**

```
这是工具类小程序，不含课程售卖、不含医疗或康复建议。
「力量水平评级」为公开标准对照的参考值，页面已标注「仅供参考」。
无登录、无支付、无分享奖励，不存在诱导分享。
```

**常见的驳回与应对**

| 驳回理由 | 大概率原因 | 怎么改 |
|---|---|---|
| 类目不符 | 选了「医疗健康」或「教育」 | 改「工具 → 健康管理」（或体育-在线健身，见 §1.2） |
| 涉及医疗健康建议 | 力量水平评级 / 训练计划表述 | 强调参考值、已在协议里写明不提供医疗建议；必要时把「建议重量」改成「参考重量」 |
| 功能不完整 | 审核员没走完引导，只看到空态 | 备注里写清「首次进入需回答三个问题生成计划」 |
| 采集信息未声明 | 剪贴板未在隐私指引里声明 | 补勾「剪切板」并写用途 |
| 诱导分享 | 目前无分享奖励 | 说明即可 |
