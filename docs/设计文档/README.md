3. 用户流程
4. 数据模型：表结构、字段说明、约束、本地存储
5. 业务逻辑：逐个功能的规则
6. 同步与边界情况
7. 接口：客户端数据层、页面改动、服务端改动

9. 现有代码需要修正的问题
10. 验收标准
