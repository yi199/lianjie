## 每份文档的结构

1. 模块概述：解决什么问题、设计原则、功能清单
2. 核心概念
3. 用户流程
4. 数据模型：表结构、字段说明、约束、本地存储
5. 业务逻辑：逐个功能的规则
6. 同步与边界情况
7. 接口：客户端数据层、页面改动、服务端改动
8. 数据量
9. 现有代码需要修正的问题
10. 验收标准
11. 待确认
