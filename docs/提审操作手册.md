## 1. 服务类目

**路径**：后台 → 设置 → 基本设置 → 服务类目 → 添加类目

### 主选：`工具 → 健康管理`

官方对该类目的描述是：**「适用于记录/测试与健康相关内容，如：身高、体重、个人身体管理记录等服务」** —— 练界做的就是「记录每组重量次数 + 身体指标 + 看统计」，一条对一条。

### 备选：`体育 → 在线健身`

官方类目表里该类目**资质要求为「/」（无资质）**，个人主体可申请。但它的适用范围写的是「提供各类型的健身运动**在线学习/在线指导**服务」—— 我们没有课程、没有教练指导，硬选它有「内容与类目不符」的风险。

> ⚠️ **这是对上一版建议的修正**。之前说「应该选体育-在线健身」，看过备案的服务内容选择指引后改口：
> 备案口径里「健身房/瑜伽/舞蹈/美体机构」（即在线健身那类）明确写着**「个人备案：不建议选择」**；
> 而「工具」类对个人主体没有这条限制。**类目和备案服务内容要一致**，两边都走「工具」最稳。

一个月内类目最多改 3 次，别一次挂一堆用不上的。

## 2. 小程序备案（唯一不能加速的一环）

**路径**：
- 未上架小程序 → 后台**首页**的「去备案」按钮
- 或 设置 → 小程序备案 → 去备案

**流程五段**：填信息 → 平台初审（1–2 工作日）→ 工信部短信核验 → 通管局审核 → 备案成功。整体 **5–15 个工作日**（官方文档口径；跨省/退回会更久）。

### 2.1 主体信息（个人）

| 栏目 | 填什么 |
|---|---|
| 地区 | 选**身份证地址所在省**（见 §0.3） |
| 详细地址 | **必须精确到门牌**（X 单元 X 楼 X 号）；无门牌就在「主体备注」写「通信地址已为最详细」 |
| 证件 | 身份证正反面，彩色、清晰、边角齐全、**有效期大于 1 个月** |

### 2.2 主体负责人 / 小程序负责人

个人主体：**小程序负责人默认复用主体负责人**（就是你本人）。
- 手机号、应急手机号、邮箱：必须是**不同人**的号码不能共用 —— 简单说，你自己的手机号 + 父母/朋友一个号 + 你的邮箱
- 人脸核身：**管理员本人**用管理员微信扫码；白墙背景、不戴帽子耳机口罩、不裸露上半身

### 2.3 服务内容标识

选与「工具-健康管理」对应的类别，**不要选任何经营性质/需要审批的**（个人主体禁止）。

> 官方原话：「若你是个人主体，请勿选择经营性质、企业/单位性质、涉及有关主管部门审批等的内容」。

### 2.4 前置审批

**选「以上都不涉及」**。健身记录不涉及医疗、视听、出版、金融任何一项。

### 2.5 备注（必填，约 20 字）

照抄这句：

```
记录用户自建的力量训练计划与每组重量次数，数据仅保存在用户手机本地，不含交易、社交、课程与医疗建议功能。
```

### 2.6 短信核验（最容易掉链子的一步）

- 短信从 **12381** 发出，收到后 **24 小时内**必须去 https://beian.miit.gov.cn/ 完成核验
- 逾期系统自动退回，**要从头再来**
- 等待期间**保持电话畅通**，管局可能打电话核实，未接会被驳回

### 2.7 坑

| 坑 | 说明 |
|---|---|
| 个人主体备案上限 **5 个** | 超了会提示「当前主体已超过小程序注册数量上限」 |
| 备案信息与小程序信息必须一致 | 之后改名称/换负责人都要走**变更备案**；不一致平台会警告/封禁功能 |
| 身份证过期 | 会被工信部比对出来，要求限期变更备案 |

## 3. 用户隐私保护指引

**路径**：后台 → 设置 → 服务内容声明 → 用户隐私保护指引（填**提审版本**）

### 3.1 核心口径：只声明你真正用到的

官方规则：**只有在指引里声明过的，才能调用对应接口/组件**；反过来，声明了没用的，等于给自己挖坑。

练界用到的**平台能力只有一项**：

| 能力 | 用在哪 | 必须声明 |
|---|---|---|
| **剪切板**（`wx.getClipboardData` / `setClipboardData`） | 我的 → 备份与恢复 | ✅ **是** |

**没有**用到的（别勾，勾了就是虚假陈述）：位置、相册/摄像头、麦克风、通讯录、手机号、微信头像昵称、微信运动、设备信息。

### 3.2 逐项怎么填

| 表单问题 | 怎么答 |
|---|---|
| 是否采集用户个人信息 | **否**（不注册、不登录、不上传；训练数据只写在本机存储） |
| 采集的信息类型 | 只勾**剪切板**（用途写「用户主动复制备份数据到剪贴板，或从剪贴板读取自己粘贴的备份」，使用场景写「我的 → 备份与恢复」） |
| 是否向第三方提供 | 否（无第三方 SDK、无广告、无统计） |
| 存储位置 / 期限 | 微信小程序本地存储，用户删除小程序或点「删除我的全部数据」即清除 |
| 是否使用人脸/位置等敏感权限 | 否 |

### 3.3 如果表单允许自定义正文，照抄这段

```
练界不收集你的个人信息，也不需要注册或登录。

1. 训练记录（计划、动作、每组重量与次数）、身体指标（体重、体脂等）只保存在你这台手机的微信小程序本地存储里，不会上传到任何服务器。
2. 本小程序未接入任何第三方SDK，不做用户画像，不投放广告。
3. 仅在你主动点击「备份」或「从备份恢复」时，会读写系统剪贴板，内容是你自己的训练数据。除此之外不读取剪贴板。
4. 你可以随时在「我的」里点「删除我的全部数据」清空本机数据，或在「备份与恢复」里导出。
5. 训练存在受伤风险，本小程序提供的计划与建议仅供参考，不构成医疗、康复或营养建议。
```

## 5. 上传与提审

### 5.1 上传（开发者工具）

1. **清缓存 → 重新编译**（避免样式缓存造成「改了没生效」）
2. 上传，版本号 `0.1.3`，备注 `首个纯本地版本`
3. 后台 → 版本管理 → 开发版本 → 设为体验版 → 自己先扫一遍

### 5.2 提审要填的

| 项 | 填什么 |
|---|---|
| 版本号 | 0.1.3 |
| 功能页面 | 选 `pages/shell/index`（tab 容器页，进去就是「今天」）作为首页展示 |
| 测试账号 | **不需要**（无登录） |
| 补充材料 | 不需要 |
| **审核备注** | 照抄下面这段 |

```
【产品性质】个人开发的力量训练记录工具，完全离线。

1. 无登录：不需要注册、授权手机号或头像昵称，打开即用。
2. 无支付、无广告、无虚拟商品、无会员。
3. 不联网：当前版本未配置任何服务器域名，训练数据仅保存在用户手机的小程序本地存储内，不会上传。
4. 隐私：已配置《用户隐私保护指引》，仅声明剪贴板（用于用户主动备份/恢复自己的数据）；小程序内「我的 → 隐私政策与用户协议」页面有完整说明，并提供「删除我的全部数据」入口。
5. 无医疗建议：训练计划里的重量与次数是通用参考，页面与协议均写明「不构成医疗、康复或营养建议」。
6. 体验路径：首次进入 → 三步选择（水平/频率/场地）→ 自动生成计划 → 今天页点「开始训练」→ 记录每组数据 → 完成出训练战报 → 数据页查看 12 周地形与日历回看。
```

### 5.3 审核时间

一般 **1–3 个工作日**（个人主体、无支付、无诱导分享的简单功能通常当天到次日）。驳回会给具体理由，改完可重新提交。

## 6. 常见驳回与应对

| 驳回理由 | 真实原因 | 怎么改 |
|---|---|---|
| 「服务类目与实际内容不符」 | 选了「在线健身」但站内没有课程/指导 | 改类目为「工具-健康管理」，或补一句说明是记录工具 |
| 「涉及医疗健康建议」 | 计划/评语里有指导性措辞 | 已在协议声明；如被追问，把「建议」类文案改成「参考」 |
| 「采集个人信息未声明」或「使用能力未声明」 | 隐私指引没勾剪贴板 | 补声明，说明用途只用于用户主动备份 |
| 「功能不完整 / 无实质内容」 | 审核员没走通流程 | 审核备注里写清体验路径（§5.2 第 6 条），必要时提供体验截图 |
| 「小程序名称与主体不符」 | 名称含机构词或与内容无关 | 改成与「练界」内容相关的个人化名称 |
| 「未备案」 | 备案还没下来 | 备案成功前**无法发布**，只能等；开发阶段用体验版不受影响 |

## 7. 建议的顺序与时间线

```
第 1 天   ① 查名称  ② 定类目（工具-健康管理）  ③ 提交备案 ← 最长的一环，先按下去
第 2 天   ④ 填隐私保护指引  ⑤ 填基本信息
第 2-3 天 ⑥ 上传 0.1.3 → 自己做体验版回归（14 项清单里挑关键 6 项）
等备案     备案中（5–15 工作日）→ 期间代码别再大改，改了要重传
备案下来   ⑦ 提审 → 1–3 天 → 审核通过后**手动点发布**
```

**三档日期**（今天是 2026-11-11）：

| | 前提 | 能上线 |
|---|---|---|
| 乐观 | 备案 5 个工作日、审核 1 天 | 11/19 – 11/21 |
| 现实 | 备案 10 个工作日、审核 2 天 | 11/26 – 11/28 |
| 保守 | 备案 15 个工作日 + 退回一次 | 12/8 – 12/12 |
