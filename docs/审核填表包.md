## 3. 用户隐私保护指引

### 3.1 逐项答案

| 表单问题 | 填 |
|---|---|
| 是否采集用户个人信息 | **否**（不注册、不登录、不上传） |
| 采集的信息类型 | 只勾 **剪切板 / 剪贴板** |
| 剪切板用途 | ①用户主动点「备份」时把本机训练数据写进剪贴板；②点「恢复」时读取用户自己粘贴的备份；③长按「反馈问题」时复制本机诊断信息，供用户自己粘贴到反馈渠道 |
| 使用场景 | 我的 → 备份与恢复；我的 → 反馈问题 |
| 是否向第三方提供 | 否（无第三方 SDK、无广告、无统计埋点） |
| 存储位置 / 期限 | 微信小程序本地存储；用户点「删除我的全部数据」或卸载小程序即清除 |
| 是否使用位置/相机/相册/麦克风/通讯录/手机号/微信头像昵称 | **全部否** |

> ⚠️ 不要勾「相册」：分享走微信原生分享（`onShareAppMessage` / `onShareTimeline`），不写相册、不调 `saveImageToPhotosAlbum`。

### 3.2 若表单允许自定义正文，整段照抄

```
力见不收集你的个人信息，也不需要注册或登录。

1. 训练记录（计划、动作、每组重量与次数）、身体指标（体重、体脂等）只保存在你这台手机的微信小程序本地存储里，不会上传到任何服务器。本小程序当前版本未接入服务器，也不含第三方SDK、广告或统计埋点。

2. 仅在你主动操作时会读写系统剪贴板：点「备份」把本机数据写入剪贴板、点「恢复」读取你复制的备份、长按「反馈问题」复制本机诊断信息。除此之外不读取剪贴板内容，也不会上传剪贴板内容。

3. 你主动把训练战报分享给好友或朋友圈时，该次训练的数字（组数、重量合计、日期等）会随分享链接一同传递，好友打开看到的是这份战报的只读副本。分享内容不含姓名、手机号、微信资料等身份信息，也不会因此获取好友的任何信息。

4. 你可以随时在「我的」里点「删除我的全部数据」清空本机数据，或用「备份与恢复」把数据导出带走。

5. 训练存在受伤风险。小程序内的计划、评级与文案均为通用参考，不构成医疗、康复或营养建议。
```

## 3.3 后台实际形态（2026-11-17 实测，照这个填）

提审页「用户隐私保护指引设置」只有两个单选项：

- ✅ 选 **采集用户隐私**。平台会按上传的代码自行识别接口（我们这一版被识别到：**读取你的剪切板**），选「未采集」等于虚假陈述。
- 点「点击完善」进入指引编辑器，里头要填三处：
  1. §1 `开发者读取你的剪切板，用途是 ____` —— **必填**。填这段（不要带句末句号，模板会自己补一个）：
     ```
     用于你在「我的 → 备份与恢复」中主动发起的训练数据备份与恢复，以及长按「反馈问题」复制本机诊断信息供你粘贴到反馈渠道。以上内容仅在本机使用，不上传、不共享
     ```
  2. §4「你的权益 → 增加联系方式」—— 只能选 **电话 / 邮箱 / 微信号 / qq** 四种之一，填你真实可用的。
  3. §5 存储期限 —— 选 **「开发者承诺…为实现处理目的所必要的最短时间」**（剪切板内容不落盘，不适用固定 X 天）。
- 最后按钮是 **「预览后提交协议」**；指引本身要单独过一次审核，和代码审核不是一回事。
